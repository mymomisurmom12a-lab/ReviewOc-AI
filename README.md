# ReviewOc AI

A Discord bot that opens a `/review` form and creates a new post in the `👾-Game-Reviews` Forum channel.

## Environment variables
- DISCORD_TOKEN: your Discord bot token
- CLIENT_ID: your Discord Application ID
- FORUM_CHANNEL_NAME: exactly `👾-Game-Reviews` unless you change it
- OPENAI_API_KEY: optional, but needed for AI-generated review wording

## Start
npm install
npm start
